# 調漲租金

## 沒有「大家一起調」這回事

**那 365 天是從「這個租客上次調漲」起算的**，或從他的租約開始日。不是從房東挑的日曆日。

330 戶橫跨三年簽約，就有 330 個不同的週年。

挑一個日曆日的話，**兩個方向同時虧**：

| | 結果 |
|---|---|
| 太早 | **通知無效**，租金停在原處，還要重新來過一輪 90 天 |
| 太晚 | 每晚一個月就是少收一個月的差額 |

所以系統裡沒有批次，只有**政策**——調多少的規則。每一戶到自己的日子，發自己的通知。

---

## 三個絕對的規則

**Alberta 沒有租金管制，金額不設上限。** 絕對的是時間和通知，而**這兩個弄錯不會讓調幅變小，是讓調漲消失**——租金停在原處，直到一份新通知走完完整的 90 天。

### 1. 距上次調漲滿 365 天

從 `last_increase_at` 算，沒有的話從 `start_date` 算。

**這兩個都是合約上寫的日期，不是簽約日、不是輸入日、不是按下送出的時間。**

合約寫 1 月 1 日起租、1 月 20 日才簽好的話：

```
照合約：2027-01-01 可調   ✓
照簽約日：2027-01-20 可調  ✗  白等 19 天
```

而且這不是一次性的偏差——**它會把這份租約往後每一年的週年都往後推**，而且沒有任何下游的東西看得出來發生過。

`last_increase_at` 原本是 `TIMESTAMPTZ`（時刻），已改成 `DATE`。存成時刻的話，1 月 1 日下午兩點半簽的租約，隔年 1 月 1 日早上算會說「還差五個半小時」——**那五個半小時來自誰幾點按了送出**。

### 2. 提前 90 天通知（按月租約）

而且**是從「視為收到」那天起算，不是寄出那天**。

| 送達方式 | 視為收到 |
|---|---|
| 親手交付 | 當日 |
| 貼在門上 | 當日 |
| Email | 當日 |
| 快遞 | +1 天 |
| **平信** | **+5 天** |

**今天寄平信、90 天後生效的通知，短了 5 天。** 那份通知無效。

### 3. 固定期租約中途不能調

租金是合約寫的，直到合約結束。**新的數字放在續約裡**，不是另發調漲通知。

系統會把固定期租約標成 `fixed_term` 並排除在外，畫面上寫明原因。

## 資料庫擋住的

觸發器會在存入時檢查兩件事：

```
ERROR: Notice for 378-519 is deemed served on 2026-08-12 and needs 90 days,
       so the earliest effective date is 2026-11-10. Serving it for
       2026-10-01 would make the increase void rather than late.
```

```
ERROR: This tenancy is not eligible until 2026-11-15. An increase effective
       2026-09-01 would be served too soon and the notice would be void.
```

**放在資料庫是因為這條規則會讓整件事作廢**，而應用程式的檢查只在有人走那條路徑時才跑。

## 流程

```
設定政策（例如 3%，上限 5%，四捨五入到 5 元）
        ↓
系統算出每一戶自己的：可服務日、生效日、調整後金額
        ↓
「今天可以發」的佇列  ←  PM 逐一或勾選多筆
        ↓
草擬通知（還沒發出）
        ↓
發出 → 記錄送達方式 → 系統算出視為收到日
        ↓
生效日到 → 排程自動改租約和收租排程
```

**批次準備、逐筆驗證。** 不能發的會列出原因，不是安靜跳過——**安靜排除一半的批次，是有人以為已經發出去的批次**。

---

## 自動套用

生效日到了，每日排程會：

- 改 `leases.rent`
- 改 `charge_schedules.amount`（**只改租金那筆**）
- 把 `last_increase_at` 設成**生效日不是今天**——下一個 365 天從租金實際變動那天算

**只改租金。** 車位和儲藏室是各自獨立的約定，跟著租金一起漲等於發了一個沒有通知過的調漲。

套用前會重新檢查兩件事：**通知有沒有被撤回、租約還在不在**。兩個都不常見，但發生時都是靜默的。

撤回之後，**如果之後還要調，90 天要從新的通知重新算**。畫面上有寫。

## 上線前

**這裡每一個數字都是法律數字**：365 天、90 天通知、各種送達方式的視為收到天數。**請律師確認過再發第一份通知。**

通知的措辭 Alberta 沒有規定表格（跟終止租約通知不同），所以系統可以組。但**請律師看過一次那段措辭**，之後就可以一直沿用。
